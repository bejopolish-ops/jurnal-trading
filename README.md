# Jurnal Trading Telegram Mini App

File project ini sudah disesuaikan agar langsung berada di root folder tanpa terbungkus sub-folder.

## Cara Pakai:
1. Ekstrak ZIP ini.
2. Unggah SEMUA file (`index.html`, `package.json`, `vercel.json`, dan folder `api/`) secara langsung ke halaman depan (root) GitHub.
